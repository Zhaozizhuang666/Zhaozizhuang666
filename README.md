## 工作方向 · What I Do

- **具身大模型评测 / ELM evaluation**：围绕感知、行动、推理决策、任务执行、鲁棒性与安全等维度设计评测用例和基准。
- **跨机器人一致性 / Cross-robot evaluation**：从任务 benchmark、关节与运控等原子能力到本体参数，比较模型在不同机器人上的表现并定位差异。
- **双臂真机测试 / Real-robot testing**：参与 MovaXHelper、力矩传感器标定、Docker 测试环境、Franka 机械臂与 RoboArena 的评测流程。
- **异常场景验证 / Edge-case testing**：针对 Agent–VLN–VLA 链路中的指令、路径和抓取异常，验证安全保护、恢复与反馈机制。
